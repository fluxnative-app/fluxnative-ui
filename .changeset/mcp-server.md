`@fluxnative/mcp`, an MCP server over the catalog layer: `search_components`, `get_component`, `get_index`, `get_design_rules`, `list_tokens` and `validate_screen`, all answered from `registry.json`, the two indexes and the eval graders, so an agent can look recipes up and check a screen instead of guessing. Runs from a checkout over stdio (`node packages/mcp/src/bin.js`).
