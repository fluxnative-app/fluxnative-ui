# @fluxnative/tokens

FluxNative UI design tokens: W3C DTCG source compiled to TypeScript constants and a Tailwind v4 / Uniwind theme.

Generate an app's Uniwind entry file with `npx fluxnative-tokens global-css --out src/global.css`.

Part of [FluxNative UI](https://github.com/fluxnative-app/fluxnative-ui). Read the [README](https://github.com/fluxnative-app/fluxnative-ui#readme) and [`docs/topics/tokens.md`](https://github.com/fluxnative-app/fluxnative-ui/blob/main/docs/topics/tokens.md) before using it.

The package ships TypeScript source and is v0: pin an exact version.
