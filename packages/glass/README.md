# @fluxnative/glass

The FluxNative UI glass ladder: native Liquid Glass, blur, translucent or opaque — chosen per device and accessibility settings.

Register native glass once in `app/_layout.tsx` with `import '@fluxnative/glass/expo'`.

Part of [FluxNative UI](https://github.com/fluxnative-app/fluxnative-ui). Read the [README](https://github.com/fluxnative-app/fluxnative-ui#readme) and [`docs/topics/glass.md`](https://github.com/fluxnative-app/fluxnative-ui/blob/main/docs/topics/glass.md) before using it.

The package ships TypeScript source and is v0: pin an exact version.
